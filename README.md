# Pozajmice

Mobilna aplikacija za evidenciju pozajmica i vraćanja po ratama.

## Tehnologije
Ionic, Angular, Firebase RealtimeDatabase (REST), Firebase Authentication

## Funkcionalnosti
- Registracija i prijava (token, automatska odjava po isteku)
- CRUD nad pozajmicama
- Beleženje uplata po ratama uz automatsko zatvaranje izmirene pozajmice
- Pretraga i filtriranje
- Statistika po dužnicima

## Pokretanje
npm install
ionic serve
